Publish with your GitHub account

There is no separate studio password. Publishing is authorized by your access to the Willy Dex GitHub repository.

  1. Open the GitHub publisher using the button above and sign in to GitHub if prompted.
  2. Click Run workflow on the main branch.
  3. Select the video type. For a segment, paste the exact start_at and end_at values shown here; for full, leave them empty.
  4. Click the green Run workflow confirmation. Your completed video will appear in the video library.

Only repository members with permission to run GitHub Actions can publish. Everyone can preview.

Published HQ videos appear in the library with their own permanent watch and download links. Open GitHub publisher directly if your browser blocks new tabs.
